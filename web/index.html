01 It's just a URL

No build step, no JavaScript recoloring, no second export. The paint is part of the address.

/drawings/tintflare-story.svg?theme=riso&tm=dark&v=1
  1. the file exactly as Excalidraw exported it, in a private B2 bucket
  2. theme which paint to use: one TypeScript file per palette
  3. tm light or dark, matching your page
  4. v bump it after a redesign; browsers cache each version for a year

    05 How the paint gets on

    1. Drop it in the bucket

      Export from Excalidraw once and upload it to a private B2 bucket. Its first 10 GB are free, and so is the egress to Cloudflare.

    2. The edge repaints it

      The Worker streams the SVG through HTMLRewriter and swaps every color with your theme's pick, or an OKLCH match that passes contrast checks.

    3. Your page just shows it

      A plain <img>. Cached at the edge and in the browser, and it works in RSS readers and with JavaScript turned off.
